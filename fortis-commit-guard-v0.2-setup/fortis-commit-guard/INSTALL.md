# Первая загрузка владельцем

Репозиторий: https://github.com/AlexPastukhh/fortis-commit-guard.
На момент подготовки пакета репозиторий публичный, Git-история пуста,
guard отсутствует в выбранных репозиториях GitHub-коннектора ChatGPT.
Ни App pilot, ни подключения чата не нужно добавлять к guard с правом записи.

## 1. Загрузить исходники через GitHub

1. Скачать архив и распаковать его. Для загрузки выполнять программы на Windows не нужно.
2. Открыть guard в своём браузере. На странице пустого репозитория выбрать
   uploading an existing file. После появления начальной ветки это Add file → Upload files.
3. Открыть распакованную папку fortis-commit-guard и перетащить её содержимое в окно загрузки.
   Должны сохраниться .github/workflows, checks, core, profiles, tests, docs и vendor.
   Не загружать сам ZIP и не создавать лишний уровень fortis-commit-guard внутри репозитория.
4. На корневом уровне должны оказаться README.md, INSTALL.md, guard.py и registry.json.
   Проверить, что оба YAML находятся именно в .github/workflows.
5. Просмотреть файлы и создать первый commit в main, например Bootstrap commit guard.

Архив предназначен для просмотра и загрузки владельцем. Его передача не является
согласованием всех будущих контрактов безопасности проекта.

## 2. Проверить сам guard

После commit должен запуститься Guard self-tests. Если GitHub предлагает включить
Actions, включить их для этого репозитория. Workflow использует GitHub-hosted Ubuntu
и не требует добавления product secrets, PAT или ключа App.

Дождаться успешного Guard self-tests. Ошибку не обходить выключением теста;
разобрать причину и исправить заготовку до использования результата.

## 3. Проверить известный пилотный коммит

Actions → Check a project commit → Run workflow:

- Branch: main.
- Project: obs-planning-docs.
- Candidate SHA: f97a3916eda2c87073417917e1d830b92138cfdb.
- Architecture: выключено для первой проверки security-набора.

Дождаться результата, открыть summary и commit-guard-report. Это пустой пилотный
коммит с тем же деревом, что у baseline. PASS показывает совместимость профиля с
этим деревом; контроль нарушений отдельно проверяется синтетическими тестами guard.

Не считать один зелёный значок разрешением запуска на Windows. Сейчас workflow
только выдаёт отчёт; автоматического импорта или слияния в проекте нет.

## 4. Защитить изменения самого guard

Когда Guard self-tests уже успешно выполнился, настроить правила для main:

- запрет удаления ветки и force push;
- изменение через pull request и обязательный Guard self-tests;
- отсутствие прав записи у подключений и automation, которыми управляет чат.

При единственном владельце не задавать схему, требующую от него одобрить собственный PR:
состав reviewers определяется вашим рабочим процессом. Обязательные тесты проверяют
корректность реализации; смысл изменения контракта рассматривает владелец.

В Settings → Actions → General использовать минимальные Workflow permissions.
Оба workflow дополнительно задают contents: read; создание и одобрение PR из workflow не нужно.

## 5. Дальнейшее подключение проектов

1. В отдельном owner-reviewed изменении добавить профиль и запись в registry.json.
   GitHub repository ID, имя и профиль должны согласоваться.
2. Описать области и возможности проекта. Для похожего userscript можно настроить
   существующий browser adapter; для другого runtime потребуется его профиль и проверки.
   Проект только с документами использует общие модули без browser adapter.
3. Добавить контрольные примеры применимости и обходов. Если нужен ручной выбор нового
   проекта в интерфейсе, добавить его в options поля project workflow.
4. Проверить существующие профили и новый проект, затем утвердить версию guard.

Эта версия получает только публичные проекты без credentials. Доступ к приватным
источникам требует отдельной read-only авторизации в доверенной среде; credential
в development Docker и процесс кандидата не передаётся.

Автоматический запуск при push, выдача status check в проекте и импорт в Windows —
следующие интеграции. Их настройка не требуется для первого ручного запуска guard.
